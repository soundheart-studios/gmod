gmod · planning and rules

Your two yeses decide everything. The rest enforces them.

Agents build the jobs you approve, CI proves the criteria you approve, and the review holds every change to the rules you accept.
1Yes to
The plan
what to build, and how it's proven
  • small jobs, one behaviour each
  • the files each job may touch
  • "done when", in plain words, each proven by a command
  • the order: phases, and what waits for what
2Yes to
The rules
what must always hold
  • a data format, a boundary, a library, a security rule
  • the files each rule governs
  • must: breaking it fails review
  • should: departing needs a stated reason
From then on, enforced
On every change
by agents, the gate and the review
  • an agent gets only its job, its files, and the rules that cover them
  • the gate proves the job's criteria fail first, then pass
  • the review checks each criterion and answers each rule
  • agents can't change the plan or the rules; only your yes can
Before you approve
Would this criterion fail if the job were wrong?Are the files tight?Are the assumptions mine?Is every must checkable in a diff?
