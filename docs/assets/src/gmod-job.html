gmod · a job's life

Each job is proven twice: by its agent, then by CI.

Plan
Ready
In the plan you approved; what it waits for is on main.
Agent
Claim
One agent takes it. No other can.
Red
It writes a test that fails.
Green
It makes the test pass, in the job's files only.
Commit
Allowed only after red, then green.
CI
Gate
Fails without the change, passes with it.
Review
Are the tests real? Anything weakened?
Main
Lands
By itself. The jobs after it become ready.
Stuck? A failed or abandoned job gets a "gmod stuck" issue.
Agent or you: the same steps, the same checks.
