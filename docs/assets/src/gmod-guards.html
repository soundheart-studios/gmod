gmod · where the rules hold

One rulebook, checked three times.

Every rule lives in one place: gmod the command. The plugin, you at a terminal, and CI all call it, so an agent hears what CI will say later.
While an agent works
The plugin
instant, worded feedback to Claude
  • editing outside the job's files
  • committing without red, then green
  • writing the plan or the rules
  • approving, or merging by hand
Before it merges
CI and protection
final: nothing reaches main without it
  • a job that isn't in the plan, or isn't claimed
  • files outside the job
  • tests that pass without the change
  • rule or CI changes mixed with code
  • anything that weakens what is checked
After it lands
CI, watching
opens an issue for a person
  • "gmod breach": something reached main without what it requires
  • "gmod stuck": a job failed, stalled or was abandoned
